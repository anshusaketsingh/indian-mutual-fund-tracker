# Indian Mutual Fund Tracker

Python-based mutual fund portfolio tracking and analysis tool.

## Project Structure
- **src/** - Python scripts
- **output/** - Generated reports and results
- **data/** - Input data files (CSV, JSON, etc.)
- **logs/** - Application logs

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Place Python scripts in `src/`
3. Add data files to `data/`

## Running
```bash
python src/main.py
```
